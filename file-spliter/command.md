# file split and store
- 파일을 라인별로 읽음
- 입력 파일은 개별 경로 또는 `*.txt`, `acb-log*.txt` 같은 파일명 패턴으로 지정함
- 원본 파일 확장자가 `.gz`이면 읽으면서 gzip 압축을 해제함
- 정규표현식으로 입력된 값과 일치하는 라인검출
  - 검출된 값으로 생성된 파일 스트림에 저장하고 없을 경우 신규로 생성함
  - 파일스트림은 생성이후 유지하며 모든 원본파일 분석이 종료된 이후 일괄종료함
- 일치하지 않는 라인은 직전에 검출된 값으로 인지함

# split 파일 분석 및 분류
- split 된 파일이 저장된 경로 지정
- 검출 패턴이 있는 파일을 분류결과로 지정된 경로에 카피

# 산출물
- single executable jar
- spring boot 최신 버전 사용

# 실행옵션
- 파일 분할은 `split`, 분석 및 분류는 `analyze` 명령으로 실행함
