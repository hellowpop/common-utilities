엔진별 시작·중지를 제어합니다. response 바인딩은 함께 제어하며, 테스트 콘솔과 기존 HTTP/HTTPS 서버는 계속 실행됩니다. 중지하면 해당 엔진의 연결과 예약 작업도 종료됩니다.

포트 정보를 확인한 뒤 서비스를 제어하세요.

01

HTTP / HTTPS REST

대기

요청 메타데이터와 수신 헤더를 JSON으로 돌려받습니다.

/api/echo

브라우저는 HTTP 버전을 강제할 수 없습니다. HTTPS에서 HTTP/2로 협상되면 이 API는 505를 반환합니다. HTTP/1.1 REST는 HTTP 콘솔에서 확인하세요. 본문은 응답에 포함되지 않습니다.

RESPONSE아직 요청하지 않았습니다
응답 상태, 헤더와 본문이 여기에 표시됩니다.
02

HTTP/2 Ping

대기

TLS ALPN으로 협상된 HTTP/2 연결의 ACK를 확인합니다.

GET/http2/pingHTTPS ONLY
서버와 브라우저, 두 곳에서 확인

응답의 protocol은 서버가 처리한 HTTP 버전입니다. 브라우저가 제공하는 전송 프로토콜도 결과에 함께 표시합니다.

HTTPS 콘솔에서 호출할 수 있습니다. 처음 접속할 때 self-signed 인증서 경고를 수락하세요.

ACK RESPONSETLS + h2
HTTP/2 연결의 ACK 응답을 기다립니다.

05

Payload 동시·반복 요청

대기

payload의 5개 필드는 배열로 입력합니다. 각 스레드가 매 반복마다 배열 값들의 모든 조합으로 본문을 생성해 endpoint에 POST합니다. 총 요청 수는 threadCount × loopCount × 조합 수이며 각 SSE 응답은 endpointUrl과 status만 전송합니다.

blockSize는 dummy 값 길이이며 HTTP 청크 크기가 아닙니다. headers는 선택 항목이고 본문 관련 헤더는 생성기가 설정합니다. HTTPS endpoint는 JVM에서 신뢰하는 인증서가 필요합니다.
