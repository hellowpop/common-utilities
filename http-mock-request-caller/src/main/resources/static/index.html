각 path의 chunked, contentType, contentEncoding, contentLength, blockSize는 배열입니다. 각 worker가 전체 조합을 반복합니다. scenarioHooks / workerHooks / pathHooks / requestHooks에 pre, post를 지정하세요.

worker.vars.put('token', 'test');
exchange.request.setHeader('X-Token', worker.vars.get('token'));
exchange.request.body = 'replacement text';
exchange.assertSuccess(exchange.response.status == 200, 'expected 200');

GET/HEAD는 contentLength:[0], contentEncoding:["IDENTITY"], chunked:[false]를 사용합니다. 본문은 작은 UTF-8 텍스트만 script에 노출되며 큰 본문은 artifact로 조회합니다. 실제 응답은 post 수정 전 원본으로 저장됩니다.
